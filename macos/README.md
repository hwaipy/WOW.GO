# WOW.GO — macOS 后台控制

原生 macOS GUI，参考 [hwaipy/WOW.GO](https://github.com/hwaipy/WOW.GO) 的控制面板、脚本动作和图像判断思路。此版是 Swift/AppKit/SwiftUI 实现，采用游戏窗口专用截图和进程定向输入。原项目的 `magic.py` 不直接兼容；控制序列用可导入/导出的 JSON 定义。

## 启动

首次运行先执行 `./build.sh` 构建应用。之后双击本目录的 **Start.command**，或在已经授权过的终端运行：

```sh
cd macos
./Start.command
```

也可以直接打开 **WowGo.app**。macOS 对终端启动与直接启动的权限归属可能不同；直接启动时，请点「授权」，在系统设置中允许 WowGo 的「屏幕与系统音频录制」和「辅助功能」，然后重新打开。重新构建后的临时签名也可能需要重新授权。

## 界面与使用

1. 运行一个魔兽世界客户端，将角色放在水边、面向水面，把钓鱼技能绑定为 **1**（右侧可以修改）。
2. 点「连接」，查看游戏实时预览。保持游戏打开并允许后台渲染，运行期间不要最小化、移动镜头或改变窗口比例。
3. 在预览里拖出水面识别区域，避开人物、任务文字、红色 UI 和别人的浮漂。
4. 点「载入钓鱼脚本」。默认跑 10 轮；可以在编辑器修改 `count`。
5. 默认「演练模式」打开：会捕获和分析真实画面，但不发送任何输入。点「合成识别演示」可在没有游戏时查看完整识别演示。
6. 关闭「演练模式」，点「运行」开始真实后台输入。然后可以正常使用其他 App。
7. 点「停止」或在本应用内按 **⌘.** 取消。切回游戏前台也会自动终止真实任务，避免与手工操作交错。

「点选浮漂」使用固定位置，适合诊断；抛竿位置会变化，连续自动钓鱼推荐「自动定位」。

左侧显示抛竿、检测到咬钩、超时次数。咬钩计数是视觉触发次数，不代表成功获得物品。日志记录执行步骤和识别结果；截图存放在应用数据目录，可点击「打开截图目录」。

## 脚本格式

所有 `x`、`y` 都是**游戏画面归一化坐标**，左上角为 `(0,0)`，右下角接近 `(1,1)`，与 Retina 像素缩放无关。可在预览中选择「拾取坐标」。

```json
{
  "name": "我的控制序列",
  "steps": [
    { "action": "key", "key": "2", "modifiers": ["shift"] },
    { "action": "wait", "seconds": 1.2 },
    { "action": "click", "x": 0.5, "y": 0.3, "button": "right" },
    { "action": "repeat", "count": 3, "steps": [
      { "action": "fish" },
      { "action": "wait", "seconds": 2 }
    ] },
    { "action": "capture" }
  ]
}
```

| 动作 | 参数 | 行为 |
|---|---|---|
| `key` | `key`，可选 `modifiers`、`seconds` | 按下并释放；时长 0.01–0.5 秒 |
| `click` | `x`、`y`，可选 `button` | 左/右键点击；坐标范围 `[0,1)` |
| `wait` | `seconds` | 可随时取消的等待，最长 3600 秒 |
| `repeat` | `count`、`steps` | 嵌套循环，次数 1–10000 |
| `capture` | 无 | 保存当前游戏窗口画面 |
| `fish` | 无 | 按当前钓鱼配置完成一轮：抛竿、定位、识别、收竿或超时 |

按键支持字母、数字、F1–F12、`esc`、`enter`、`tab`、`space`、`delete`、方向键，以及 `-`、`=`。修饰键支持 `shift`、`ctrl`、`alt`、`cmd`。整份脚本在执行前校验；不执行 Python、shell 或任意代码。

附带 `scripts/fishing.json`、`fish-once.json`、`sequence-example.json`。地图鼠标测试脚本里的关闭按钮坐标对应当前游戏 UI 布局，不是通用地图识别。

## 钓鱼识别

- 默认搜索红色浮漂，使用连通区域筛选，连续三帧稳定后锁定。
- 锁定位置附近建立逐渐更新的基线，比较局部颜色变化和中性颜色像素的相对增亮。
- 水花不必是纯白，适用于本次暴风城阴影水面的灰色水花。
- 满足「变化比例」与「水花增量」两个阈值，首帧超过阈值、下一帧保留至少 35% 的变化后右键收竿。
- 8 秒内未定位浮漂或单轮超时就跳过，不执行猜测点击。
- 不同浮漂、光照、镜头、水面和 UI 布局需要调参；当前不使用机器学习模型，也不读取游戏内存。

## 后台输入边界

- ScreenCaptureKit 仅过滤魔兽世界主窗口，使用单个 12 FPS 捕获流；预览闲置时约 2 FPS 更新。
- 每次输入检查进程身份与前台状态，多个游戏进程会拒绝连接。
- 所有鼠标/键盘事件只通过 `CGEvent.postToPid` 投递到游戏进程。
- 不调用全局 `CGEvent.post`、光标移动、游戏窗口激活，也不修改系统全局键盘状态。
- 鼠标先发送游戏进程内的位置事件，再发送带窗口号的按下/释放。当前客户端还需要鼠标 subtype 3 和 `CGEventSetWindowLocation` 系统接口；后者是未公开 API，系统升级可能失效。接口缺失时拒绝点击，不回退到全局鼠标控制。
- 停止和关闭应用时，已按下的键/按钮仍会配对释放。游戏退出、窗口消失、画面长期不更新会终止任务。
- 运行日志中的“执行完成”表示序列执行完毕；游戏是否接受操作应以画面和实际效果确认。

## 构建与验证

无需第三方依赖，使用 macOS Command Line Tools：

```sh
./build.sh
./WowGo.app/Contents/MacOS/WowGo --integration-test
./WowGo.app/Contents/MacOS/WowGo --probe
```

`build.sh` 编译 app、临时签名并运行识别和脚本校验测试。集成测试验证循环、动作顺序、合成咬钩到右键收竿以及取消后不再输入。`--probe` 连续读取 12 个真实窗口帧并报告候选浮漂坐标。

命令行执行脚本（默认演练，只有 `--real` 才发输入）：

```sh
./WowGo.app/Contents/MacOS/WowGo --run-script scripts/fish-once.json --real
```

可加 `--trace-dir /tmp/wow-trace` 保存定位图、变化最大帧、水花最大帧和逐帧 CSV，便于微调。不要同时运行多个自动化实例。

设置、脚本及截图保存在 `~/Library/Application Support/WowGo/`。启动默认恢复脚本和参数，但不会自动开始输入。
